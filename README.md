# מרחב – ניהול משימות חכם

מערכת אישית לניהול משימות במרחבים (בית, עבודה, לימודים ועוד), בעברית ומימין לשמאל, עם סוכן AI מובנה.

## מה יש בפנים

- **מרחבים** – לכל מרחב צבע ותצוגה: קנבן (גרור ושחרר), רשימת TODO לפי עדיפות, או לוח שנה חודשי. אפשר להחליף תצוגה בכל רגע.
- **משימות** – כותרת, עדיפות (נמוכה / בינונית / גבוהה / דחוף), תאריך יעד וסטטוס (חדשה / בעבודה / בהשהייה / הושלמה).
- **דשבורד** – בחירת מרחבים (נשמרת), משימות דחופות / להיום / באיחור וכרטיס סיכום לכל מרחב.
- **סוכן AI** – צ'אט בצד המסך. עובד על מרחב אחד או על כולם, מבצע פעולות על המשימות, ומבקש אישור לפני פעולה על יותר מ-3 משימות או מחיקה.

### כלי הסוכן

| כלי | מה הוא עושה |
| --- | --- |
| `get_tasks` | קריאת משימות עם סינון |
| `add_tasks` | הוספת משימות |
| `update_tasks` | עדכון (לפי מזהים או לפי סינון, כולל הזזת תאריכים) |
| `delete_tasks` | מחיקה (תמיד באישור) |
| `summarize_tasks` | סיכום וסטטיסטיקות |
| `daily_briefing` | סיכום יומי ידידותי ל-ADHD: 3 משימות פוקוס, איחורים, ניצחונות קטנים |

האישור נאכף בצד השרת: כשפעולה חורגת מהסף השרת עוצר, שומר אותה, ומבצע רק אחרי לחיצה על "אשר".

## הרצה מקומית

```bash
npm install
cp .env.example .env.local   # ומלא את הערכים
npm run dev
```

משתני סביבה: `DATABASE_URL`, `OPENAI_API_KEY`, `APP_PASSWORD` (ואופציונלי `OPENAI_MODEL`, `AUTH_SECRET`).

הטבלאות נוצרות אוטומטית בבקשה הראשונה, ובהרצה הראשונה נטענים נתוני דוגמה (3 מרחבים ו-15 משימות).
